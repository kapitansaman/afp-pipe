# Practical writing and translation

The active scoped-evidence writer now produces direct HTML from the existing approved brief. The historical structured renderer remains available for old artifacts/tests, but is not the active generator.

Removed from the active writer: provider strict JSON schema, per-paragraph fact-ID declarations, exact section/paragraph counts and paragraph-level 50-word minimum. A 49-word paragraph is a warning, not a failed article.

Deterministic repairs: one unambiguous object wrapper, html/content_html alias, canonical title when omitted, FAQ field alias, inert HTML fences/formatting, trailing unclosed safe tags and an omitted excerpt copied from existing prose. Conflicting outputs, unsafe HTML/links and invented prose are never repaired into approval. Raw candidates and repair receipts are retained.

Retained: canonical intent, verified sources and approved numbers, 550–2500 overall meaningful words, a useful sourced table, three FAQs, no substantive repeated paragraphs or mixed-language contamination, mandatory independent final evidence/commercial review, all image and publication safeguards. Product links are added by the existing site renderer, not invented by the model.

Translations use bounded text chunks and preserve HTML/URLs on the server. Each chunk has a source-bound create-once reservation and raw-response digest. Paid successful chunks are reused. Changed IDs/numbers, wrong scripts, changed sources and uncertain reserved requests remain blockers. No retry through another key after provider failure.

The one-off verification is nonpublishing: one writer, one final audit, four target languages, no images and no WordPress calls. It uses at most the 13 remaining calls from the original 24-call pilot, with its original 11 requests retained. It does not reset exhausted text attempts or replace the old family artifacts. No scheduled generation is enabled by this change.
