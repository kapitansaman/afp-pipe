## داشبورد و درصد پیشرفت

- داشبورد عمومی: https://getsalet.github.io/nono/
- صفحه داخل مخزن: `docs/agri-v2/PROGRESS.md` روی feature branch.
- داده مرحله‌ای: `data/agri-v2/status/live.json`؛ دارای مرحله، درصد، زمان، لینک اجرای جاری و آمار واقعی رسیدهای انتشار است.
- صفحه وب هر ۱۵ ثانیه داده را می‌خواند. کش GitHub ممکن است تغییر تازه را دیرتر نشان بدهد؛ لینک Actions برای جزئیات اجرای جاری در صفحه هست. زمان‌ها به وقت تهران نمایش داده می‌شوند.
- درصد سهم مراحل تکمیل‌شده کار جاری است، نه تخمین زمان سپری‌شده یا تکمیل کل ۲۹۰۵ عنوان. وضعیت idle به معنی نبود موضوع آماده است؛ آخرین کار و مانع قبلی جدا حفظ می‌شوند.
- وضعیت فقط هنگام مراحل واقعی ثبت می‌شود. هیچ کلید، رمز، هدر Authorization، URL اتصال خصوصی یا متن خام خطای سرویس در داشبورد/مخزن ثبت نمی‌شود.
- `GITHUB_TOKEN` فقط برای نوشتن دو فایل وضعیت روی feature branch در runner استفاده می‌شود. CI و اجرای محلی بدون `AFP_PROGRESS_ENABLED=1` گزارش زنده نمی‌نویسند. commit وضعیت `[skip ci]` است.
- فایل زمان‌بندی روی main تنها router است و feature branch را checkout می‌کند. گردش‌کار مستقل Pages فقط پوشه `docs/agri-v2-dashboard` را منتشر می‌کند؛ کد تولید، Secrets یا خروجی داخلی دیگری وارد سایت Pages نمی‌شوند. گردش‌کارهای قدیمی مخزن دست‌نخورده‌اند.

## اتصال و ایمنی

WordPress native REST با حساب اختصاصی `afp_agri_v2_bot`، شناسه ۲، نقش author. Secrets: `AFP_WP_BASE_URL`, `AFP_WP_USERNAME`, `AFP_WP_APP_PASSWORD`. مقدار رمز در مخزن یا جلسه نوشته نشده؛ نسخه موقت محلی آن حذف شده است. SQL مستقیم، FTP، دست‌کاری دیگر نوشته‌ها، حذف یا ادغام جمعی فعال نیست.

ویرایش/بازگردانی فقط نوشته دارای همان ID، مالک حساب فنی و marker موضوع است. بازگردانی مجاز ابتدا draft می‌شود؛ پس از تکمیل رسانه و کنترل تغییر نسخه، همان نوشته publish خواهد شد. slug متعلق به دیگری خطای توقف است. URL تصویر دریافتی از سرویس فقط HTTPS و میزبان عمومی، بدون userinfo و بدون انتقال هدر احراز هویت پذیرفته می‌شود؛ تصویر رمزگشایی و محدودیت اندازه بررسی می‌شود.

پایلوت بازبینی AI مبتنی بر سه منبع دانشگاهی MSU/WSU/ISU دارد؛ تأیید انسانی کارشناس کشاورزی ثبت نشده و نباید جعل شود. توصیه عددی بی‌منبع، نسخه سم/کود یا تعمیم تاریخ برداشت به همه مناطق مجاز نیست.
