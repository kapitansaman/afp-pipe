## Forward-only production selection

After the existing local-first research/review is absent or insufficient:

1. Select only source URLs explicitly linked by approved facts AND listed in the current brief sources. Prioritize uncovered numeric facts, then retain the other declared claim-source leads in stable order. General qualitative model knowledge without a URL does not cause a URL to be invented. Original approval is not scientific acceptance for a new language.
2. When such leads exist, the international fallback retrieves those exact declared URLs instead of spending two generic discovery searches on potentially unrelated documents. It makes no new search/model-planning request. No leads means the existing bounded international search flow remains unchanged.
3. The existing source loader still enforces URL/redirect safety, technical-host admission, text/hash/layout checks and the six-hour fresh-cache TTL. Stale original texts are refetched or marked unavailable, never imported as current evidence. The same six-URL phase ceiling applies; more required leads fail explicitly instead of truncating or expanding the budget. A failed fetch does not trigger a second automatic fetch/discovery round.
4. Seed URLs are part of the immutable collection contract. Changed seeds cannot overwrite/reuse an old search plan. Local-first documents remain present; any refreshed same-URL document, merged pack, IDs, catalogs, prompt and model response are rebound to the actual NEW inputs. Old receipts and unknown reservations cannot replay.
5. The independent reviewer still checks the complete article/facts/full source texts. Catalog v2 numeric/negative consistency and all unchanged scientific, geographic, source and publication gates remain. Original-source retrieval is not a positive verdict.

Historical AR/EN diagnostics remain frozen on their explicit retained packs. No new admission, reservation, model call, source fetch, article/translation edit, source approval, publication, schedule or stage promotion is created by this offline code change.
