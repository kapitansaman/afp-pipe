# کاشف و ترمیم منابع — نسخه اول

نقش اجرایی جدید پیش از استخراج شواهد در `research.prepare_one` فراخوانی می‌شود و از مدل متنی فعلی `agnes-2.5-flash` استفاده می‌کند؛ مدل، کلید یا سرویس جست‌وجوی تازه‌ای لازم نیست.

مسیر خانواده: کاشف منابع ← اعتبارسنج فنی دریافت ← استخراج‌کننده شواهد ← بازبین مستقل ← نویسنده ← تصویرساز و کنترل کیفیت ← انتشار. دریافت فنی قبل از انتخاب مدل هم اجرا می‌شود؛ دسترسی به متن واقعی شرط انتخاب است.

## کشف واقعی و محدودیت آن
- URL دیگر از حافظه مدل تولید نمی‌شود. ابتدا کاتالوگ منابع بررسی‌شده خوانده می‌شود. در کمبود منابع، صفحات شروعِ تعریف‌شده و لینک‌های واقعاً مشاهده‌شده در HTML با واژگان موضوع جست‌وجو می‌شوند.
- این روش کشف محدود در سایت‌های مؤسسات است، نه موتور جست‌وجوی جامع اینترنت. اگر پوشش کاتالوگ و صفحات شروع کافی نباشد، نقش با گزارش کمبود منبع متوقف می‌شود. برای جست‌وجوی عمومیِ جاری در GitHub Actions باید در آینده backend واقعی و دسترسی آن تنظیم شود؛ ابزار وب این چت داخل Actions در دسترس نیست.
- سقف هر موضوع: دوازده URL یکتا، سه دریافت هم‌زمان، گسترش لینک فقط یک سطح؛ حداکثر یک درخواست مدل برای انتخاب شناسه سند، بدون retry پنهان. محدودیت شش URL هر batch، اندازه HTML و کش شش‌ساعته حفظ می‌شود.
- حداقل دو مؤسسه مستقل؛ لینک، متن و محدودیت دامنه به مدل داده می‌شود. مدل فقط شناسه‌های موجود را انتخاب می‌کند، نه URL آزاد. انتخاب کاشف تأیید ادعا یا مجوز انتشار نیست.

## اصلاح دریافت و ایمنی
حداکثر چهار تغییرمسیر و پنج پاسخ در یک زنجیره؛ HTTPS، دامنه مجاز، نبود نام کاربری/رمز و عمومی‌بودن DNS در هر گام کنترل می‌شود. تغییرمسیر به HTTP، دامنه غیرمجاز، شبکه خصوصی، حلقه، میزبان نامعتبر و پاسخ بیش‌ازحد بزرگ رد می‌شوند. URL نهایی و زنجیره نگهداری و مقصدهای تکراری حذف می‌شوند. سند با هش یا ساختار نامعتبر وارد کش و استخراج نمی‌شود.

PDF در این نسخه پشتیبانی نمی‌شود و صریحاً رد می‌شود؛ منابع جدید HTML هستند. خطای ۴۰۴ با حدس‌زدن مسیر یا کاهش معیارها پوشانده نمی‌شود.

## موضوع متوقف‌شده کدو
کاتالوگ نسخه چهار سه صفحه دریافت‌شده از دو دانشگاه را اضافه می‌کند. این منابع درباره میوه کامل کدو هستند، نه نگهداری تخمه جداشده. کاشف و بازبین باید ابهام محصول، نیاز عددی/محلی و اختلاف گونه/رقم را رد کنند. افزودن URL تضمین آماده‌شدن همین عنوان برای انتشار نیست.

## حفظ پیشرفت
بودجه قبلی پژوهش، توقف‌های کیفیت، کلیدها، صف، تصاویر و رسیدهای انتشار بازنشانی نمی‌شوند. نسخه تازه کاتالوگ فقط همان مسیر موجود تلاش دوم برای خطای کمبود منبع را قابل بررسی می‌کند؛ اجرای جدید خودکار مجاز نمی‌شود. درخواست کنترل‌شده قبلی مصرف‌شده باقی می‌ماند و انتشار و زمان‌بند متوقف می‌مانند.

## گزارش‌ها و آزمون
`source-discovery-report.json`: منشأ لینک و نتایج دریافت؛ `source-scout-report.json`: تصمیم نقش و محدودیت‌ها. استخراج و نقد مستقل همچنان گزارش جدا دارند. پروب دستی اختیاری فقط یک انتخاب منابع انجام می‌دهد؛ به وردپرس، تصویرساز، شرح تأییدشده یا شمارنده تلاش تولید دست نمی‌زند و رزرو پایدار مانع تکرار درخواست مدل در اجرای مجدد است.
