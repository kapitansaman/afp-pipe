# Regional-first research with credible international completion

Owner policy: Persian → Iran; Tajik → Tajikistan; Russian → Russia; Arabic → Arab countries, not only Iraq; English → English-speaking countries, not only the US. Preserve legacy `ar-IQ`/`en-US` locale IDs, paths, slugs and language bridge. Explicit country membership is in `data/agri-v2/regional-research-policy.json`.

## Evidence priority

1. Search official regional government/academic technical sources first, in the audience language. Iran uses deterministic Persian official-domain queries. Other audiences use a bounded target-language query planner; Russian-language discovery for Tajikistan is allowed, but a Russian publisher does not become Tajik evidence.
2. If regional coverage is weak or missing, use actually fetched credible international universities, institutional science and the existing explicit research/journal registry. Document the precise regional gap; preserve original geography, methods, soil, water, cultivar, production-system and unit limitations. One trial is not a national or multi-country recommendation. No source-country relabeling or invented local rates/dates/prices.
3. Regional government/academic namespace admission is not scientific approval or study-location proof. Reject arbitrary country TLDs and lookalike hosts. All existing per-hop HTTPS, public-DNS, size, PDF and literal-quotation guards remain in place.
4. IRNA and Khovar are explicitly recognized official news sources for contextual discovery only; news is not admitted into the technical claim pack. Even a government-domain news story cannot replace a technical publication: the independent reviewer must assess the actual fetched text.

## Runtime path and bounded work

- New scoped Persian research collects two local searches and up to six fetched documents. If source sufficiency is weak, it adds two international searches/up to six documents; if local documents pass source count but fail exact intent/claim extraction, the existing bounded source-repair path handles the substantive gap with the regional rule in its researcher/reviewer contract. All search calls use the shared Tavily reservation/cache and unchanged 80/run, 1000/month ceilings.
- New regional source reviews must explicitly affirm regional priority and retained international transfer limits; foreign evidence needs a substantive local-gap explanation. New briefs bind the regional profile, independent review, facts and sources. They do not receive publication permission from a country label alone.
- Each translated version independently searches and reviews the approved facts and complete article against regional evidence. Only after a negative/weak local review or no local documents does its international-completion path fetch additional evidence. Every fact needs a literal technical excerpt and explicit scope; foreign fallback also needs a local gap and transfer-limit confirmation. Translation still preserves all facts, numbers, uncertainty, country labels and units; this is not permission to invent different national prescriptions or rewrite approved Persian evidence.
- Locale research planner/reviews use the existing request-reservation helper, within the same four-model-call attempt, three-attempt/twelve-call item budgets. If research uses the available budget, fidelity work remains pending for a later allowed attempt; neither acceptance nor extra budget is invented. Uncertain reservations require reconciliation, including when an older linguistic approval exists. Search-only Persian collection never instantiates a text-model client.
- The independent language queue initializes/persists shared search accounting and carries forward the primary pool's same-run usage, so two pools cannot each spend the 80/run allowance. Already linguistically approved, unpublished languages are eligible for missing regional checks without resetting attempts. The publisher treats missing regional evidence as a research hold, not a failed WordPress mutation.
- Locale evidence binds original article, brief, fetched text hashes and review. Checked supplementary references appear only in the final bibliography alongside the original evidence; original citations are not deceptively replaced with unrelated local sites. Same-language related-link rules remain unchanged.

## Migration and limits

Existing published articles, approved source/translation files, original evidence and unknown-outcome fences are not rewritten or auto-approved. Historical research-route contracts remain valid for audit; new regional routes are explicit. New Persian publication of an old brief requires fresh regional research/review rather than silently backfilling a pass. Old pending families may therefore hold for explicit research migration; this patch does not claim they have already passed the new policy.

No image/key assignment, provider backoff, family counter, scheduled trigger, cohort promotion, source observation or local agronomic prescription is changed. Activation requires merging this patch into the operational branch; no production generator run is part of the patch verification.
