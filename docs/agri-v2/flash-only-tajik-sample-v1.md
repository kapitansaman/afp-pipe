# Flash-only Tajik diagnostic

Explicit user scope: text Flash 2, 2.5 and 3 only. No Pro models. Future automatic
alternative selection is restricted to these Flash IDs as well.

At most one generation request per catalog-advertised model, three total. This
is the new user-requested fixed model test, not a reset of the earlier five-call
repair budget (4 spent, 1 remains unused). No retries, production model change,
translation overwrite, WordPress/image calls or scheduling changes.

Each tested model gets the exact same four actual source/Tajik segments from the
saved carrot candidate: IDs 35, 52, 53, 57. They include bitter taste, germination,
carrot identity, 55–65 °F and 14–21 days. The prompt supplies the source-bound
Tajik glossary as feedback against the old review's incorrect crop assertion.
This tests using feedback and correcting a short translation sample; it is NOT
an independent blind vocabulary benchmark or final full-article fidelity review.

The bounded checks require confirmed response model identity, exact segment IDs,
number and °F preservation, Cyrillic without Persian residue, carrot identity and
withdrawal of the prior false crop claim. Passing does not establish full Tajik
fluency or publication approval. Sample texts remain diagnostic artifacts only.
Unlisted Flash IDs are explicitly marked not tested, never confused with listed
image models. Provider limits/authentication failures stop the test, not key hop.
