    گزارش و کنترل اجرا

    گزارش اجرای جاریصفحه وضعیت داخل مخزنگردش‌کار زمان‌بندی

    لینک آخرین نوشته فقط پس از تأیید انتشار و دسترسی به صفحه عمومی نمایش داده می‌شود و با خطای اجرای بعدی حذف نمی‌شود. این صفحه هر ۱۵ ثانیه آخرین وضعیت ثبت‌شده را می‌خواند؛ کش GitHub ممکن است نمایش تغییر تازه را با تأخیر همراه کند. درصد، سهم مراحل تکمیل‌شده کار جاری است؛ نه درصد زمان سپری‌شده یا تکمیل کل ماتریس. زمان‌بندی GitHub ممکن است با تأخیر اجرا شود. چرخه، حداکثر یک عنوان را پژوهش و در صورت تأیید منابع و هم‌پوشانی تولید می‌کند. موفقیت اجرای GitHub لزوماً به معنی انتشار نیست. موضوعات عددی و تخصصی بدون بررسی لازم منتشر نمی‌شوند. هیچ کلید API یا اطلاعات ورود در این صفحه قرار ندارد.
