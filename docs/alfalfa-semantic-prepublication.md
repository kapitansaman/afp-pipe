# One-shot alfalfa semantic prepublication stage

Manual mode: `alfalfa-semantic-prepublication` on the existing production feature branch only.

The fixed request binds the accepted corrected Persian article, brief, regional verdict, authenticated read-only snapshot (less than 24 hours old), complete 25-document related-content inventory, both original image byte hashes, AFP reference and review code.

A durable create-only reservation prevents replay, including unknown model outcomes. The maximum is 12 text-model requests: five complete-document semantic batches, two fresh actual-byte visual reviews, then (only after every semantic and visual gate passes) four staged translations and one independent fidelity review. Every document is included without truncation; stable quote IDs resolve to exact original passages. Ordinary shared topic coverage is not forced novelty, while substantive conflict or duplication blocks progression. Both image audits run even if one rejects; uncertain crop identity blocks translation. No replacement images or automatic repair attempts are made.

This stage does not contact or change WordPress, search, upload, reset attempts, or publish. Model credentials are narrowly filtered and exclude site and GitHub credentials. Existing artifacts are protected; reports preserve negative outcomes. Even successful translations still require separate regional/publication review and explicit owner authorization before any same-post update.
